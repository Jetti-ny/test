# 꿈길 진로설계

대학생이 **우리 학교의 학과와 교육과정을 한눈에 보고**, 꿈꾸는 진로를 고르면
그 분야에 맞는 **과목 · 학과 · 연계 전공(복수전공/부전공) · 자격증 · 활동**을 추천받는 서비스의 MVP입니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 교육과정 둘러보기 | 대학을 고르면 개설 학과와 학년별 과목, 각 과목이 기르는 역량을 보여줌. 선택한 진로와 관련된 과목은 강조 표시 |
| 학과 적합도 | 진로가 요구하는 역량을 각 학과 교육과정이 얼마나 다루는지 % 로 계산 (학과가 아직 없으면 "추천 학과"로 활용) |
| 역량 갭 분석 | 내 전공만으로는 채우지 못하는 역량을 표시 |
| 연계 전공 추천 | 갭을 가장 많이 메우는 학과를 복수전공/부전공으로 제안하고, 이수 시 커버리지 변화(예: 67% → 100%)를 보여줌 |
| 과목 추천 | 내 전공 과목, 타과 수강 과목, 교양 과목을 진로 적합도 순으로 정렬 |
| 수강 로드맵 | 현재 학년부터 4학년까지 학기별 추천 과목 |
| 자격증·활동 | 진로별 추천 자격증(실제 국내 자격증)과 대외활동 |

## 실행

빌드가 필요 없는 정적 웹페이지입니다.

```bash
open index.html        # 브라우저로 바로 열기
npm start              # 또는 로컬 서버로 실행
npm test               # 추천 로직 테스트
```

## 구조

```
index.html             화면
src/data.js            대학·학과·과목·진로·자격증 데이터
src/recommend.js       추천 엔진 (브라우저/Node 공용)
src/app.js             화면 렌더링
src/styles.css         스타일 (다크모드·모바일 대응)
tests/                 node:test 테스트
```

### 추천 방식

과목과 진로를 같은 **역량(skill) 사전**으로 연결합니다.

- 과목: `skills: ["database", "data"]` — 이 과목에서 기르는 역량
- 진로: `skills: { database: 3, programming: 3, ... }` — 필요한 역량과 중요도(1~3)

과목 점수 = 겹치는 역량의 중요도 합, 학과 적합도 = 학과 전체 과목이 다루는 역량의 가중 비율입니다.

## 데이터에 대해

- **대학교와 교육과정은 시연용 가상 데이터**입니다(한빛대·미래과기대·누리대).
- 실제 서비스로 확장하려면 각 대학 학사요람/교육과정 공개 자료를 `src/data.js` 와 같은 구조로 수집하면 됩니다.
- 자격증은 실제 국내 자격증 기준이지만, 응시 요건·일정은 시행기관 공지를 확인해야 합니다.
